## Expansion Pack challenges (must address all three)

- ~**1,600** servers: 900 on-prem VMs, 600 AWS/Azure, 100 boutiques  
- OS mix: Rocky, Ubuntu, CentOS Stream, Amazon Linux  
- Critical patch automation fails on 600+ hosts → miss 30-day window  

### 2. Untraceable administrative changes / extended outages
- Out-of-band SSH edits undocumented  
- High MTTR; revenue-impacting e-commerce outages  

### 3. Operational skills gap for containers
- Developers hand over complex `podman run` lines  
- Ops typos and weak observability → developer dependency
